# 悬浮窗系统托盘角标（显示/隐藏入口）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给悬浮窗加系统托盘图标，作为显示/隐藏入口，解决最小化后窗口无法恢复的问题。

**Architecture:** 主进程 `main.js` 创建 `Tray`（内嵌 base64 PNG 图标，不新增资源文件），左键点击/右键菜单切换 `win.show()/hide()`；标题栏「—」按钮从 `win.minimize()` 改为 `win.hide()`（IPC 事件名 `win-minimize` → `win-hide`）。

**Tech Stack:** Electron ^31（`float-window/node_modules` 已有），纯 JS 无构建步骤。

## Global Constraints

- 悬浮窗保持 `skipTaskbar: true`，不占任务栏。
- ✕ 按钮语义不变：`app.quit()`。
- 托盘图标用 spec 中批准的内嵌 base64（`data:image/png;base64,...` 前缀），不得新增图标文件。
- 改完代码按仓库约定提交（`fix:`/`feat:` + 中文描述），float-window 改动不跑 tsc/vsce。
- 验证方式：杀掉 electron 进程后重启（见每任务验证步骤），无自动化测试框架。

- [ ] **Step 2: 新增 toggleWindow 与 createTray 函数**

`createWindow` 函数定义之后（`function createWindow() {...}` 结束的 `}` 之后）插入：

```js
function toggleWindow() {
  if (!win) return;
  if (win.isVisible()) {
    win.hide();
  } else {
    win.show();
    win.focus();
  }
}

function createTray() {
  try {
    tray = new Tray(nativeImage.createFromDataURL(TRAY_ICON_DATA_URL));
    tray.setToolTip('韭菜悬浮窗');
    tray.on('click', toggleWindow);
    tray.on('right-click', () => {
      tray.popUpContextMenu(
        Menu.buildFromTemplate([
          { label: '显示/隐藏悬浮窗', click: toggleWindow },
          { type: 'separator' },
          { label: '退出', click: () => app.quit() },
        ])
      );
    });
  } catch (err) {
    console.error('托盘创建失败：', err.message);
  }
}
```
